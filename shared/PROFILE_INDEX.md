# Profile Index

## personal

Use for relationships, daily life, feelings, values, people, and personal history.

## creative

Use for creative coding, client websites, net art, browser experiences, design, and artistic practice.

## bioinformatics

Use for MGH/work, antibody/bioinformatics tasks, scientific workflows, scripts, and research operations.

## Cross-profile rule

Profiles can know what the other profiles are for, but should not load another profile's full memory by default.
